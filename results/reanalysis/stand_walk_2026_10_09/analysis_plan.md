# 8채널 Stand–Walk 재검토 계획

2026-10-09. 기존 결과를 이미 본 뒤 사용자 질문에 따라 정한 후향적 탐색이다. 사전등록이나 독립 재현으로 부르지 않는다. 새 결과를 보기 전에 검사 범위를 기록한다.

## 확인할 질문

1. 감각운동 mu/beta 반응과 MI의 관계는 문헌에서 어디까지 확인되는가? 대역의 변화, 운동 관련 발생원, 실제 심상 수행, 조건 분류를 분리한다.
2. 프로토콜의 복합사지 요소는 무엇인가? 인수인계 슬라이드 16에는 오른발+왼팔로 시작해 오른발·왼발 총 두 걸음이라고 적혀 있다. 2.5초에 전환했다는 기록은 없다. 사용자는 실제 반복·시작 방향·전환 시점이 달랐을 가능성을 지적했다. 이는 가능한 수행 변이이지 관찰된 수행 기록이 아니다.
3. 고정 시점 평균에 가려진 Stand–Walk 차이가 8채널 파워, 기준선 대비 변화, 시간 궤적, 시점/방향에 둔감한 변화 특징, 공간 공분산에 남는가?
4. 같은 참가자의 다른 시행, 시간적으로 떨어진 시행, 보지 않은 참가자로 일반화되는가?

## 경쟁 설명과 판별 예측

| 후보 | 기대되는 관찰 | 관찰되어도 남는 한계 |
|---|---|---|
| 한 번 좌우 전환, 시점·시작 방향이 일정하지 않음 | Walk의 자유 전환점 대비/좌우 궤적 변동 증가 | 잡음이나 주의 변화도 같은 통계량을 키울 수 있음 |
| 여러 번 좌우 교대 | Walk의 편측성 저주파 변조·교차 횟수 증가 | 5초 창으로 정확한 상상 보행 주기를 복원하기 어려움 |
| 안정적 공간·대역 차이 | 평균 파워/공분산으로 보류 시행 분류 | 운동심상 고유 발생원은 확인되지 않음 |
| 사람마다 다른 패턴 | 개인 내 분류가 참가자 간 분류보다 높음 | 낮은 전이만으로 개인화 신경기전을 확정할 수 없음 |
| 세션 상태·순서·단서 효과 | 단서 전 분류 또는 시간 분리 시 성능 하락 | 원인 식별에는 추가 대조/계측이 필요함 |
| 현재 측정에 구분 정보가 약함 | 여러 특징과 모델에서 평가 성능 불안정 | 모든 가능한 모델의 정보 상한이나 MI 불이행 증명은 아님 |

## 자료와 전처리

- 기존 검증된 연속 캐시의 10명, Rest/Stand/Walk 각 50시행을 출발점으로 한다. 기존 시행 보존 규칙과 코드 2/5/8 매핑을 유지한다. 식별자와 EEG 배열은 로컬에 둔다.
- FC3, FC4, C3, C4, Cz, CP3, CP4, CPz 전부 사용한다. 이 몽타주는 운동영역 주변에 모여 있으며 전두극·후두극을 포함하는 전뇌 8채널은 아니다.
- 고정 Butterworth 대역필터를 연속 런에 적용하고 사건에 맞춰 자른다. 귀 참조와 CAR를 모두 비교한다. CAR의 랭크 감소는 OAS 공분산 수축으로 수치 안정화한다. 이를 생리학적 발생원 분리로 표현하지 않는다.
- 4–8, 8–13, 13–20, 20–30 Hz를 사용한다. 30–45 Hz는 품질/민감도 진단이며 근전도 확정 지표가 아니다.
- 기준선 [-4.5,-2.5]초, 과제 [0,5]초. 평균 파워는 길이 맞춘 1초 창의 로그파워를 평균한다. 주 분류 파워는 [0.5,4.5]초, 변화 특징은 [1,5]초와 기준선의 차이. 시간 특징은 0.5초 창/0.25초 간격으로 [0.25,4.75]초 내부에서 계산한다.
- 자동 ICA/CCA가 MI를 정제했다고 가정하지 않는다. 눈/근육 참조가 없으므로 원인별 제거 성공을 검증할 수 없다. 극단값의 영향은 사전에 고정한 로컬 윈저화 민감도로 확인한다.

## 신호 특징과 통계

- 모든 채널의 시간별 로그파워, FC/C/CP 좌우쌍 및 측방 평균의 편측성, 중앙 대비 측방/앞뒤 대비를 사용한다.
- 자유 전환점 대비, 시간 SD, 범위, 평균 중심 교차, 0.2–1.0 Hz 변조량은 시행마다 레이블 없이 계산한다. 최대값 선택은 잡음에서도 증가하므로 클래스 대비와 가상 신호 검사를 함께 쓴다.
- Stand–Walk와 각 조건–Rest 대비는 참가자별 평균 차이로 요약한다. 10명이 추론 단위다. 다수 특징의 탐색에는 Holm 보정을 적용하고 효과량·참가자별 방향·95% 구간을 함께 기록한다. 시행 1,500개를 독립 참가자처럼 세지 않는다.
- 시간 순서 앞/뒤 절반의 방향 일치와 참조 방식 민감도를 기술한다. 두 절반은 독립 연구가 아니다.

## 분류 평가

- scikit-learn/pyRiemann의 검증된 구현을 사용한다. 정적 파워, 기준선 변화, 시간 궤적, 전환 시점/방향에 둔감한 특징, 필터뱅크 공간 공분산을 비교한다. 선형 로지스틱, RBF SVM, 수축 LDA/CSP, 리만 접공간 및 제한된 트리 모델을 후보로 둔다.
- 모델/특징/참조 선택은 외부 5-fold의 학습 자료 안에서 내부 3-fold로 한다. 표준화, 특징 선택, CSP, 접공간 기준은 매 학습 폴드 안에서 적합한다. 외부 시험 정확도로 후보를 선택한 최고값은 최종 성능으로 부르지 않는다.
- 개인 내 무작위 층화 분할과 시간순 연속 블록 분할을 별도로 평가한다. 시간순 분할에서는 시험 블록 양옆 1시행을 학습에서 제외한다. 이는 미래 예측 전용 분할이 아니라 세션 내 시간 블록 일반화다.
- 참가자 간 평가는 1명 전체를 보류하는 LOSO, 내부 선택도 참가자 그룹을 분리한다. 시험 참가자의 레이블이나 통계량으로 보정하지 않는 평가를 기본으로 한다.
- 정확도와 균형정확도를 모두 기록한다. 참가자 평균과 95% t 구간은 탐색적 기술이며, LOSO에서는 학습 집합 중첩으로 구간의 해석에 추가 제약이 있다.
- 분류가 개선되어도 조건 라벨의 정보라는 결론과 MI 고유 생리기전이라는 결론을 구분한다. 개선되지 않아도 원 데이터에 아무 정보가 없다는 결론으로 확대하지 않는다.

## 문헌·출처 경계

STEAM 폴더의 인수인계 PPTX, 분석 코드/초안/README, 제공된 현재 대화의 사용자 진술을 조사한다. Claude 원 대화 전체는 제공되지 않았으므로 모든 과거 언급을 찾았다고 하지 않는다. 논문 검색은 PubMed, 출판사, 저자 공개 전문을 대상으로 한 질문 중심의 제한 조사이며 체계적 문헌고찰은 아니다. 외부 주장은 새 맥락의 독립 검증자가 확인한다.

## 첫 결과 뒤 추가한 검증

23개 고정 후보의 개인 내 외부 평가를 모두 본 뒤, 최대 평균 정확도 55.9%를 관찰했다. 이 최고값을 검증 성능으로 채택하지 않는다. 여러 후보 중 하나가 우연히 높아질 가능성을 확인하기 위해 `check_search_optimism.py`를 추가했다. 199회, 각 런 내부 시간순 Stand/Walk 시행 10개 이하 블록 안에서 레이블을 섞고, 23개 고정 후보 × 두 분할 방식의 최대 참가자 평균 정확도를 매번 다시 계산한다. 관찰 최대값은 이 최대값 분포와 비교한다. 이는 사후 탐색의 전체 후보군 검사이며, nested 선택 알고리즘의 순열검정이나 독립 자료에서 선택 모델의 55.9% 성능 검증은 아니다. 블록 내부의 조건부 교환가능성을 가정한다.

그 뒤 추가한 안정성 검사는 첫 무작위 CV seed와 별도 4개 seed를 **전부 평균**한다. 가장 좋은 seed를 채택하지 않는다. 참가자별 다섯 반복 평균을 먼저 구한 다음 10명을 요약하며, 50개 반복 점수를 독립 표본으로 세지 않는다.

추가 전처리 대조는 동일 8–30 Hz 공분산 모델에서 극단값 완화 전·후를, 동일 파워 로지스틱 모델에서 8채널·중앙 2채널·측방 6채널을 비교한다. 기존 필터뱅크 공분산과 단일 대역 robust 공분산의 차이를 전처리 효과로 오인하지 않는다.

최초 LOSO 결과 뒤 사람 간 파워 수준 차이의 영향을 살피는 두 민감도를 추가했다. 시행별 공분산 trace 정규화는 시험 참가자 집단 통계량을 쓰지 않는다. 참가자별 Euclidean whitening은 시험 참가자의 **레이블 없는 150시행 전체**로 참조를 맞추는 사후 오프라인 보정이다. 후자는 시험 신호의 분포를 활용하는 transductive 평가이며 완전히 새 사람의 무보정 일반화와 구분한다. 각 민감도의 C는 외부 학습 참가자들 안에서 그룹을 나눈 내부 검증으로 고른다. 두 민감도 중 외부 결과가 높은 쪽만 최종 성능으로 선택하지 않는다.
