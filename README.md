# Lower-limb motor imagery on an 8-channel wearable EEG montage

Manuscript draft and analysis code for a bounded negative result: whether
**rest**, **standing-up** and **walking** motor imagery can be decoded from a
consumer-grade 8-channel montage (Bitbrain Versatile, 256 Hz), ten
participants, 50 trials per class.

**Short answer.** Rest is detectable against both imagery conditions
(64–66 %). Standing and walking imagery are not separable from one another
(53.1 %, *p* = .246 at the participant level), and the null is bounded four
independent ways rather than merely unachieved.

## Data availability

**Raw recordings are not included.** They are human subjects data and their
release is governed by the study's ethics approval. `results/` contains the
derived statistics and figures only, with participants labelled `S01`–`S10` in
recording-date order.

To run the pipeline on your own recordings, point `STEAM_DATA_DIR` at a
directory holding one folder per recording session:

```bash
export STEAM_DATA_DIR=/path/to/BBRaw
python code/01_diagnose.py
```

Otherwise the default is `<repo>/data/1. BBRaw`.

`cache/` (preprocessed `.npz`, ~240 MB) is regenerated from the raw files and
is not tracked.

## Pipeline

Run in order; each stage writes to `results/`.

| `03_transfer.py` | cross-participant transfer (not used: within-subject constraint) |
| `04_deep.py` | EEGNet benchmark |
| `05_optimize.py` | per-participant filter-bank optimisation |
| `06_ceiling.py` | trial and electrode ceiling curves |
| `07_svw_focus.py` | 840-configuration exhaustive search |
| `08_s06_hypothesis.py` | is the one significant participant an existence proof? |
| `09_stats.py` | permutation nulls, Holm, Nadeau–Bengio corrected *t*-test |
| `10_s06_physiology.py` | **Table III** — physiological screen of that participant |
| `11_neuro_criterion.py` | M1–M4 prespecified criterion |
| `12_manipulation_check.py` | imagery versus the visually matched rest condition |
| `13_time_laterality.py` | six timing-free tests of within-trial alternation |

| `21_me_discriminate.py` | spectral shape, beta rebound, executed-movement decoding |

| `md_to_docx.py` | manuscript → `.docx` |

## Reproducing a number

Every result in the manuscript names its source script in square brackets, so
`[`19_topography_floor.py`]` after a table means that table is regenerated by
running that file. Numbers in `results/*.csv` are the values quoted in the
text.
